# TreinadorAI

Serviço planeado da plataforma RunningAI e futuro projeto final de um módulo do curso.

O objetivo é criar um assistente de treino que use o contexto e a evolução do atleta para apoiar a definição e adaptação de planos. O código, os dados, os modelos, os testes e a documentação deste projeto ficarão nesta pasta.

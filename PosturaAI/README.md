# PosturaAI

Serviço planeado da plataforma RunningAI e futuro projeto final de um módulo do curso.

O objetivo é analisar a postura e a técnica de corrida, apresentar indicadores úteis ao atleta e integrar os resultados na aplicação Flask. O código, os dados, os modelos, os testes e a documentação deste projeto ficarão nesta pasta.
